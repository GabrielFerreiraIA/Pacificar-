---
description: Inicia uma sessão de trabalho no PACIFICAR seguindo o protocolo do AGENTS.md
---

1. Leia o `AGENTS.md` da raiz se ainda não leu nesta conversa.
2. Rode `npm run status` e `npm run log:ultimos` e resuma para o usuário: progresso, o que está em andamento e as pendências dos últimos logs.
3. Proponha UMA tarefa da lista "PRONTAS PARA AGENTE" que não conflite com as trilhas em andamento (PLANO.md → Trilhas). Espere o usuário confirmar.
4. Rode `npm run tarefa -- iniciar T-NN antigravity` e faça o commit: `git commit -m "[T-NN] iniciar" -- finalizacao/TAREFAS.md`.
5. Leia os detalhes e o critério de aceite da tarefa em `finalizacao/TAREFAS.md` e a seção relacionada do `finalizacao/PLANO.md` antes de começar.
